## Resumen rápido

- **Punto de entrada principal:** `python menu.py`
- **Administración del catálogo (CRUD):** `python crud.py`
- **Persistencia:** `autos.json` (catálogo) y `rentados.json` (alquilados)
- **Lenguaje:** Python 3 (solo biblioteca estándar)
